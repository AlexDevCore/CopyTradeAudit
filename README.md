# CopyTradeAudit — v1.0

Локальный исследовательский инструмент для проверки одной честной гипотезы:

> Можно ли получать положительный результат, наблюдая за публичными решениями
> исторически успешных трейдеров на Polymarket, если учитывать реальную цену
> входа, задержку обнаружения, ликвидность, комиссии, проскальзывание и
> изменение позиции?

**Это не обещание прибыли.** Основной допустимый ответ системы — `NO TRADE`.

## Режим

Первая версия — **строго paper trading** (симуляция без реальных денег).
Live-режим отсутствует; под него оставлены только пустые интерфейсы-заглушки
за выключенным feature-flag. Приватные ключи не используются и не хранятся.

## Статус (v0.0)

Собирается детерминированное ядро (Фаза A), тестируемое офлайн без сети:

- `src/domain/`    — модели (сделка, стакан, решение) и параметры стратегии
- `src/normalize/` — сделки трейдера → чистая экспозиция → «решения»
- `src/scoring/`   — win/loss, сырой и скорректированный (Wilson) win rate
- `src/paper/`     — симуляция исполнения по стакану (комиссии, проскальзывание, частичное)

Дальше (Фаза B+): `ingest/` (Gamma/Data/CLOB), `store/` (SQLite),
`signal/`, `risk/`, `audit/`, `web/`. См. `docs/DESIGN.md`.

## Установка

Требуется [`uv`](https://docs.astral.sh/uv/) и Python 3.12+.

```bash
uv sync
```

## Тесты

```bash
uv run pytest -q
```

## Запуск (заглушка окружения)

```bash
uv run python -m src.main
```
